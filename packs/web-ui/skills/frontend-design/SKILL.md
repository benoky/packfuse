# Frontend design

## Workflow

1. Read existing tokens, typography, components, layout patterns, and the main user task.
2. Plan visual hierarchy and responsive behavior around real content. Match the product's typography, spacing, and color. Avoid a generic AI look, such as purple-on-white, unless that is the brand. Reuse existing components.
3. Implement normal, loading, empty, and error states as relevant. Preserve keyboard access and clear focus indicators.
4. Inspect representative viewport sizes and exercise the primary flow. Check overflow, contrast, and labels; explain any unverified browser behavior.

## Completion

A working interface that follows the product's visual language, with evidence of responsive and interaction checks. A screenshot alone is not enough.
