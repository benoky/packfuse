# Web design guidelines

## Workflow

1. Check whether an official Vercel implementation is available. This wrapper shares its name, so do not invoke itself recursively.
2. Use the official source at https://github.com/vercel-labs/agent-skills when available; otherwise label the audit as a limited local checklist.
3. Inspect semantic structure, keyboard operation, focus, contrast, labels, validation messages, and responsive overflow on the requested flow.
4. Report reproducible issues with affected component, user impact, and a fix/check. Do not claim full standards compliance from a spot check.

## Completion

Prioritized audit findings, tested flow/viewport, and the scope of guidance used.
