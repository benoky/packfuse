# Receiving code review

## Workflow

1. Read each comment with the current code and intended behavior. Group duplicates.
2. Classify each as valid, needs clarification, or disagreed with evidence. Do not implement a suggestion that breaks a requirement.
3. Apply valid changes in coherent groups and run the checks affected by each group.
4. Report each comment as addressed, deferred, or declined with reason and verification. Do not send external replies without authorization.

## Completion

A comment-to-resolution list and verified changes.
