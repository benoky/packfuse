# Promotion criteria

Propose only when the visible conversation shows a repeated, stable procedure (for example, the user has restated it about three times).

- Reusable across future tasks, with clear trigger and exclusions.
- Existing skills or repository rules do not already cover it.
- A short universal constraint becomes a rule; a conditional multi-step procedure becomes a skill.
- Prefer explicit invocation for infrequent, expensive, or externally consequential workflows.
- Suggest once per pattern after active implementation finishes; missing a suggestion is acceptable.
- Drafting and file creation are separate actions. Preserve authorization already given by the user.
