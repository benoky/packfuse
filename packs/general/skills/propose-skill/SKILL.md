# Propose skill

## Workflow

1. Identify the repeated procedure from visible user instructions; consult [promotion criteria](references/promotion-criteria.md).
2. Choose a short always-on rule for a universal constraint, or a skill for a conditional procedure. Check existing skills for overlap.
3. Draft name, trigger, exclusions, inputs, steps, output, and completion checks; recommend automatic or explicit invocation.
4. Present the draft for review. Create files only after the user requests creation; do not infer authorization from a promotion suggestion.

## Completion

A self-contained draft and explanation of the recurring need. No hidden prompts or other chats are evidence.
