# ADR

## Workflow

1. Read existing ADR conventions and identify exactly one decision.
2. Collect constraints, evidence, alternatives, and the selected option.
3. Use [the ADR template](references/template.md); state status, consequences, and any follow-up checks.
4. Link superseded decisions instead of silently rewriting historical rationale. Verify referenced paths.

## Completion

One decision record whose status distinguishes proposed from accepted.
