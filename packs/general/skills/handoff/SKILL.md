# Handoff

## Workflow

1. Read the current diff and authoritative project documents. Separate completed, in-progress, and unverified work.
2. Record goal, agreed decisions, relevant files, executed checks, and constraints.
3. Name the next concrete task and any exact reproduction or command needed to continue.
4. Omit secrets, discarded exploration, and claims about unseen work. Include branch/revision only when actually checked.

## Completion

A paste-ready note another agent can follow without the prior conversation.
