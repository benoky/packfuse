# Onboard a repository

## Workflow

1. Read existing AGENTS.md and equivalent instructions before proposing a new file.
2. Find authoritative install, development, build, lint, and test commands in project configuration.
3. Map important source, test, and generated directories and point to relevant deeper instructions.
4. Draft concise commands and paths, marking unavailable commands unverified. Preserve existing project-specific constraints.

## Completion

An onboarding instruction draft with verified paths and command sources. Write only the requested file.
